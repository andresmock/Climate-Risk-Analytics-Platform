# Vision

## Overview

The Climate Risk Analytics Platform is a long-term open-source project that demonstrates modern data engineering and analytics practices on Google Cloud Platform (GCP).

The project is intended as a reference implementation rather than a production system. Its primary goal is to showcase how a scalable, well-documented, and maintainable analytics platform can be designed using open data sources and industry best practices.

## Motivation

Many data engineering portfolios focus on isolated coding exercises or simplified datasets. This project takes a different approach by building an end-to-end analytics platform around a realistic domain.

Climate and weather data provide an ideal foundation because they are publicly available, continuously updated, and naturally evolve into increasingly complex analytical use cases.

The project will gradually grow over time, following the same iterative approach used in real-world data platform development.

## Initial Scope

The first milestone focuses on collecting and analysing weather data from public sources.

Open-Meteo has been selected as the initial data source because it provides reliable, free, and well-documented weather data suitable for building the first version of the platform.

Future iterations may integrate additional datasets related to climate risks, natural hazards, geography, demographics, or other relevant domains.

## Guiding Principles

- Use only publicly available datasets.
- Build the platform incrementally.
- Focus on maintainability and engineering quality.
- Document architectural decisions throughout the project.
- Apply modern data engineering best practices.
- Treat the project as a continuously evolving reference implementation.

## Long-Term Vision

The long-term vision is to build a comprehensive Climate Risk Analytics Platform that evolves from a modern cloud-native data platform into an end-to-end analytics and AI ecosystem.

The project will start with reliable data ingestion, modelling, and analytics using publicly available weather data. Over time, it will expand to integrate additional data sources such as natural hazards, geography, land use, and socio-economic indicators.

As the platform matures, it will explore increasingly advanced data science topics, including statistical modelling, machine learning, climate anomaly detection, forecasting, and risk scoring. The platform will also investigate how large language models (LLMs) and AI agents can interact with well-governed analytical data products.

Rather than focusing on a single machine learning model or research question, the project aims to demonstrate how modern data engineering, analytics, data science, and AI can be combined within a scalable cloud architecture to support climate-related decision making and risk assessment.
